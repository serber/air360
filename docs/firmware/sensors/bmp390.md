Barometric pressure and temperature sensor from Bosch Sensortec. The BMP390 measures
pressure and temperature only — it has no humidity channel.

## Transport

- I2C, bus 0 (SDA=GPIO8, SCL=GPIO9)
- Default address: `0x77` (SDO/ADDR pin high); `0x76` selectable when the ADDR pin is low
- Clock: 100 kHz (inherited from the shared I2C bus)

## Initialization

1. Resolve the bus id via `context.i2c_bus_manager->getMasterBusHandle()` to obtain the `i2c_master_bus_handle_t`
2. Build a `bmp390_config_t` with the configured I2C address and the default sampling profile (see below)
3. Create the sensor handle via `bmp390_init()` with the resolved bus handle and config

The BMP390 component uses the new ESP-IDF I2C master API. `getMasterBusHandle()` borrows the underlying handle already owned by `i2cdev` after `I2cBusManager::init()` runs. `bmp390_init()` reads and validates the chip ID internally.

The driver sets the sampling profile field-by-field rather than using the component's `I2C_BMP390_CONFIG_DEFAULT` macro, because that macro lists designated initializers out of declaration order and trips the project's `-Werror=missing-field-initializers`. The values mirror the macro:

| Field | Value |
|-------|-------|
| `power_mode` | `BMP390_POWER_MODE_FORCED` |
| `iir_filter` | `BMP390_IIR_FILTER_OFF` |
| `pressure_oversampling` | `BMP390_PRESSURE_OVERSAMPLING_8X` |
| `temperature_oversampling` | `BMP390_TEMPERATURE_OVERSAMPLING_8X` |
| `output_data_rate` | `BMP390_ODR_40MS` |

## Polling

Each poll cycle:
1. Read temperature and pressure in a single call via `bmp390_get_measurements()`
2. Validate that neither value is NaN
3. Convert pressure from pascals to hectopascals (divide by 100) before storing

In forced power mode, `bmp390_get_measurements()` re-triggers a one-shot conversion on each call by writing the power-control register and polling for data-ready, which suits the multi-second polling model and keeps the sensor in sleep between reads.

## Measurements

| Measurement | ValueKind | Unit |
|-------------|-----------|------|
| Temperature | `kTemperatureC` | deg C |
| Pressure | `kPressureHpa` | hPa |

## Notes

- The BMP390 exposes two I2C addresses selected by the ADDR/SDO pin: `0x77` (high, default) and `0x76` (low). Note that `0x76`/`0x77` overlap with the BME280/BME680 address range — do not place a BMP390 on the same address as another climate sensor on the same bus.
- The component reports pressure in pascals; the measurement pipeline stores hectopascals, so the driver divides by 100.
- The driver uses the `k0i05/esp_bmp390` managed component (v1.2.7), which requires `i2c_master_bus_handle_t` (new ESP-IDF I2C master API).
- If the measurement returns an error or NaN, the driver keeps short glitches local and marks the sensor for reinitialization after three consecutive poll failures.

## Recommended poll interval

Minimum 30 seconds.

## Component

`k0i05__esp_bmp390` (managed component, version 1.2.7)
