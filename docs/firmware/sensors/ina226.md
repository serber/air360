DC current, voltage, and power monitor from Texas Instruments with an I2C interface. Higher-accuracy successor to INA219, with a wider bus voltage range (up to 36 V) and a narrower shunt ADC full-scale range. Measures via a shunt resistor placed in series with the load.

## Transport

- I2C, bus 0 (SDA=GPIO8, SCL=GPIO9)
- Default address: `0x40`
- Allowed addresses: `0x40`, `0x41`, `0x44`, `0x45` (set by A0/A1 solder-jumper pads on common breakout modules; the INA226 chip itself supports 16 addresses `0x40`-`0x4F` via SDA/SCL-strapped combinations, but those require cutting a trace and are not exposed on the typical two-jumper module)
- Clock: 100 kHz

## Hardware

The INA226 requires a shunt resistor between VIN+ and VIN− to measure current. Standard breakout modules include a `100 mΩ` (R100) shunt resistor on the board — no external resistor is needed.

Wiring the module in series with the load:

```
Supply (+) → VIN+  [INA226 module]  VIN− → Load (+)
Supply (−) ──────────────────────────────── Load (−)
```

The INA226 GND pin must share ground with the ESP32 GND and the supply negative terminal.

## Initialization

1. Borrow the shared I2C master bus handle via `context.i2c_bus_manager->getMasterBusHandle()` (same ownership model as BMP390 — the driver never deletes the bus, only its own device)
2. Build an `ina226_config_t` with `record.i2c_address`, 100 kHz clock, `INA226_AVG_MODE_1`, `INA226_VOLT_CONV_TIME_1_1MS` for both shunt and bus voltage, and `INA226_OP_MODE_CONT_SHUNT_BUS` (continuous measurement)
3. Initialize the device via `ina226_init()`
4. Calibrate via `ina226_calibrate()` with `max_current = 0.8 A` and `r_shunt = 0.1 Ω` (100 mΩ)

## Polling

Each poll cycle:
1. Read bus voltage via `ina226_get_bus_voltage()` — returns volts; stored as mV
2. Read current via `ina226_get_current()` — returns amps; stored as mA
3. Read power via `ina226_get_power()` — returns watts; stored as mW

## Measurements

| Measurement  | ValueKind      | Unit |
|--------------|----------------|------|
| Bus voltage  | `kVoltageMv`   | mV   |
| Current      | `kCurrentMa`   | mA   |
| Power        | `kPowerMw`     | mW   |

## Notes

- The shunt resistance is hardcoded to `0.1 Ω` (100 mΩ), matching the standard R100 shunt on common INA226 breakout modules — the same value used by the INA219 driver. If the module uses a different shunt value, this constant must be changed in the driver.
- Unlike INA219 (gain-selectable shunt range up to ±320 mV), the INA226 shunt ADC has a fixed full-scale range of ±81.92 mV. With a `100 mΩ` shunt this caps measurable current at roughly `0.8 A` — well within range for monitoring the ESP32 device's own power draw, but not suited to measuring a solar panel's or battery's full charge/discharge current without swapping to a smaller shunt resistor.
- Negative current readings indicate that the VIN+ and VIN− connections are swapped. Swap the wires at the terminal block to correct polarity.
- The INA226 bus voltage measurement is referenced to the VIN− pin relative to GND. If GND is not shared with the supply negative, voltage readings will be incorrect.
- Motors and other inductive loads generate back-EMF spikes that can corrupt I2C transactions. If the firmware crashes under motor load, add a 100 nF ceramic capacitor across the motor terminals and ensure solid decoupling on the INA226 VCC line.
- If any read call returns an error, `initialized_` is reset and the sensor re-initializes on the next poll cycle.
- The descriptor declares `startup_phase = SensorStartupPhase::kBeforeNetwork`, so the INA226 is one of the two sensor types that start polling at boot step 5, before the modem, Wi-Fi, BLE, and every other sensor are powered. Its bus-voltage reading is therefore available while the supply is still lightly loaded. See [../startup-pipeline.md](../startup-pipeline.md#sensor-startup-phases).

## Recommended poll interval

Minimum 5 seconds. The INA226 in continuous mode updates its registers roughly every 2.2 ms (1.1 ms shunt + 1.1 ms bus conversion time at 1x averaging); the 5 s floor is the Air360 system minimum.

## I2C address selection

| A1 pad | A0 pad | Address |
|--------|--------|---------|
| GND    | GND    | `0x40` (default) |
| GND    | Bridged to VCC | `0x41` |
| Bridged to VCC | GND | `0x44` |
| Bridged to VCC | Bridged to VCC | `0x45` |
