# LMP91000 AFE

## Status

Implemented on the `feature/lmp91000-afe` branch; not yet verified on hardware. Keep this document aligned with the LMP91000 driver and registry defaults.

## Scope

This document covers the Air360 driver for the LMP91000 AFE board: an LMP91000 potentiostat and an ADS1115 ADC that read a 3-electrode electrochemical cell (Winsen ME3 series). It describes the I2C binding, the fixed analog configuration, polling, and the reported value.

The board keeps the cell's working and reference electrodes at the same potential (0 mV bias) and converts the cell current into a voltage around a fixed internal zero. The ADS1115 digitises that voltage and the board's 2.5 V reference. Unlike the [ME3-NO2](me3_no2.md) analog path, the signal can swing in both directions around the zero, so oxidising gases such as NO₂ are not clipped at 0 V.

## Transport

- I2C, bus 0 (SDA=GPIO8, SCL=GPIO9), 100 kHz
- LMP91000 address: `0x48` (fixed in silicon; the only allowed record address)
- ADS1115 address: `0x49` (ADDR tied to VDD on the board; derived by the driver, not stored in the record)
- The LMP91000 only answers on I2C while its MENB pin is low; the board pulls MENB to GND through a 10 kΩ resistor.

## Hardware

| Board net | Connected to |
|-----------|--------------|
| `VOUT` → RC filter → `AOUT` | ADS1115 `AIN0` |
| `VREF` (LM4040, 2.5 V) | LMP91000 `VREF`, ADS1115 `AIN1` |
| `WE`, `RE`, `CE` | Cell electrodes |
| `JP1` | Manual WE–RE short |

Fit the `JP1` jumper only while the board is unpowered or the cell is in storage. Remove it before running; while fitted, the cell signal is shorted and reads as zero.

## Initialization

1. Create i2cdev descriptors for the LMP91000 (record address) and the ADS1115 (`0x49`) on the record's bus.
2. Check that both devices acknowledge.
3. Poll the LMP91000 `STATUS` register until `READY` is set (up to 200 ms).
4. Unlock (`LOCK = 0x00`), write `TIACN = 0x1C` (TIA gain 350 kΩ, RLOAD 10 Ω) and `REFCN = 0xC0` (external reference, internal zero 67 %, bias 0 %), lock again, then write `MODECN = 0x03` (3-lead amperometric cell).
5. Read `TIACN`, `REFCN`, and `MODECN` back and fail init if they differ from what was written.
6. Record the configuration time to start the warm-up window.

## Polling

Each poll cycle:

1. Run a single-shot ADS1115 conversion of `AIN1` (VREF) and then `AIN0` (VOUT): PGA ±4.096 V, 8 SPS, about 135 ms each.
2. Reject a VREF outside `2.3..2.7 V` as a hardware fault (counts as a poll failure).
3. For the first 5 minutes after init, report "Warming up" and store no measurement; the cell is still charging after the LMP91000 starts driving it.
4. Compute the signal as `VOUT − 0.67 × VREF` and report it in millivolts.

Read failures go through the shared soft-fail policy; three consecutive failures trigger re-initialisation.

## Notes

- **The driver reports the cell signal, not a gas concentration.** Convert with `ppm = signal_mV / (350 kΩ × sensitivity)`, where the sensitivity comes from the cell's label or datasheet (for ME3-NO2: about `−0.78 µA/ppm`, roughly `−270 mV/ppm`). The sign of the signal depends on the gas.
- The TIA gain, internal zero, and bias are compile-time constants. Cells that need a bias voltage, or a different gain, are not configurable yet.
- At 350 kΩ the usable range is roughly `±5 ppm` for an ME3-NO2 cell. Winsen ME3 cells resolve `0.1 ppm` at best, so ambient ppb-level monitoring is out of reach.
- New cells need the manufacturer's preheat (48 h for Winsen ME3) before readings settle. The 5-minute warm-up only covers the power-on transient.
- The registry does not reserve `0x49` for the ADS1115. No other supported sensor uses that address today.

## Recommended poll interval

The default interval. Electrochemical cells respond in tens of seconds (T90 < 25 s for ME3-NO2), and each poll blocks for about 300 ms while the two conversions run.

## Component

`esp-idf-lib/i2cdev` (raw register access; no LMP91000 or ADS1115 component)
